# KERNSEITE

Repository der Website von **KERNSEITE – Eliyah Korb**, einem Digitalstudio aus
Würzburg für individuelle Unternehmenswebsites.

Die vollständige Website (Astro, TypeScript, eigenes Design-System) wird auf dem
Feature-Branch `claude/feat-kernseite-website-5cid9c` entwickelt und anschließend
per Pull Request nach `main` übernommen.

> Dieser Stand auf `main` ist ein neutraler Ausgangspunkt. Die ausführliche
> Projekt- und Entwicklerdokumentation folgt mit dem ersten Feature-Merge.
